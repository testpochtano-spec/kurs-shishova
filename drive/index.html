Private desktop application

VideoUpload Automation

A locally operated video workflow that prepares clips, transfers them to Google Drive, and hands them to the owner's configured publishing schedule.

This application is used by its operator for accounts and content they own or are authorized to manage. It is not a public registration service. This website provides information about the application; video processing and authorization run on the operator's computer.

Google Drive integration

The operator authorizes the desktop application with Google. The upload component requests https://www.googleapis.com/auth/drive.file to work with files created by, or explicitly made available to, the application. It uploads prepared videos to the configured Drive folder and reads file identifiers and metadata to track delivery and avoid duplicate uploads.

This authorization does not grant access to every file in the Google account. A separately configured service account can read working folders that the operator has explicitly shared with it.

Publishing workflow

  1. The operator configures source media, destination accounts, and a publication schedule.
  2. The desktop application prepares clips and associated titles, descriptions, and cover images.
  3. Prepared content is transferred to the working Drive folder and the local publication queue.
  4. Separately authorized integrations deliver content to enabled destinations, which may include YouTube, VK, Instagram, Threads, and TikTok.

Media and text may be processed by Google Vertex AI/Gemini or a local Ollama model when those features are enabled. Google authorization credentials stay in the local configuration and are not published on this website.
